# Biblioteca Musical con API

Buscador de álbumes con TheAudioDB, resultados, detalle y biblioteca local.

## Tecnologías

- React
- Vite
- React Router
- TheAudioDB API

## Instalación y ejecución

```bash
npm install && npm run dev
```

Comprobaciones disponibles: `npm run lint` y `npm run build`.

## Uso

Busca álbumes, consulta el detalle y revisa la biblioteca.
